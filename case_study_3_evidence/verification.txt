Checked on 2026-10-13. Nothing was adjusted to make values match.

How the check was done
- Each experiment was re-run on a copy of the repository, so the committed result files were not overwritten.
  After the runs, `git status` and `git diff` show no changes to any tracked file.
- Every re-run produced output IDENTICAL to the committed result file (every number, compared as parsed JSON).
- Paper values were then compared with the re-run numbers, rounded to the paper's precision.
- Table IV means are computed from the raw per-split vote counts. The script's own summary rounds each rate to
  4 decimals before display, which can move the last digit (see the note under Table IV).
